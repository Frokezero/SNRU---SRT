1. ชื่องาน

ภาษาไทย: การพัฒนาระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรม คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร

2. ผู้เสนอโครงงาน

ชื่อ-สกุล: นาย กฤษฎา ศรีคิลิน      รหัสประจำตัว: 67102122111
หลักสูตร: เทคโนโลยีคอมพิวเตอร์และดิจิทัล คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร

กิจกรรมนักศึกษาถือเป็นกลไกสำคัญในการพัฒนานักศึกษาตามกรอบมาตรฐานคุณวุฒิระดับอุดมศึกษาแห่งชาติ โดยมีบทบาทในการปลูกฝังวินัย ภาวะผู้นำ จิตสาธารณะ ความสามัคคี ตลอดจนการเสริมสร้างทักษะทางสังคม (Soft Skills) ที่จำเป็นต่อการประกอบอาชีพในอนาคต คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร ได้กำหนดให้นักศึกษาทุกคนต้องเข้าร่วมกิจกรรมเสริมหลักสูตรและสะสมหน่วยชั่วโมงกิจกรรมให้ครบถ้วนตามเกณฑ์เพื่อเป็นเงื่อนไขประกอบการสำเร็จการศึกษา

อย่างไรก็ตาม จากการศึกษาสภาพการดำเนินงานในปัจจุบัน พบว่ากระบวนการบริหารจัดการกิจกรรมยังคงอาศัยรูปแบบดั้งเดิมที่ก่อให้เกิดปัญหาหลายด้าน ประการแรก การประชาสัมพันธ์และการรับสมัครผ่านเอกสารหรือฟอร์มออนไลน์ทั่วไปขาดการเชื่อมโยงฐานข้อมูลส่วนกลาง ทำให้ไม่สามารถควบคุมจำนวนผู้เข้าร่วมให้พอดีกับความจุของสถานที่จัดงานได้อย่างแท้จริง ประการที่สอง การเช็คอินหน้างานด้วยการเซ็นชื่อบนกระดาษก่อให้เกิดความล่าช้า แถวยาวสะสม และมีความเสี่ยงสูงต่อการลงชื่อแทนกัน (Proxy Attendance) ประการที่สาม การส่งหลักฐานภาพถ่ายมีความกระจัดกระจาย อาจารย์และเจ้าหน้าที่ต้องเสียเวลาตรวจสอบเอกสารจำนวนมากแบบแมนนวล ส่งผลให้นักศึกษาไม่ทราบสถานะคะแนนสะสมแบบเรียลไทม์ และมักพบปัญหาคะแนนไม่ครบก่อนสำเร็จการศึกษา ประการที่สี่ เกียรติบัตรยังออกในรูปแบบกระดาษหรือไฟล์ภาพทั่วไปที่ขาดระบบการตรวจสอบความถูกต้องแบบดิจิทัล ทำให้มีความเสี่ยงต่อการปลอมแปลง และประการสุดท้าย ขาดระบบแจ้งเตือนกำหนดการกิจกรรมล่วงหน้าแบบเจาะจงบุคคล ทำให้นักศึกษาพลาดกิจกรรมสำคัญ

โครงงานนี้จึงมีเป้าหมายในการพัฒนาระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรมแบบบูรณาการ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร (SNRU SciTech Activity System) ในรูปแบบเว็บแอปพลิเคชันที่รองรับการใช้งานบนทุกอุปกรณ์ โดยนำเทคโนโลยีระบุพิกัดตำแหน่งทางภูมิศาสตร์ (GPS Geolocation ร่วมกับขั้นตอนวิธี Haversine) ควบคู่กับรหัสคิวอาร์แบบใช้ครั้งเดียวที่มีการลงลายมือชื่อดิจิทัล (Dynamic HMAC-SHA256 Token) เพื่อเช็คอินหน้างานอย่างแม่นยำ ป้องกันการทุจริต พร้อมทั้งพัฒนาระบบคิวสำรองอัตโนมัติ (Waitlist Queue), ระบบตรวจสอบและบีบอัดภาพหลักฐานที่ปลอดภัย, ระบบเกียรติบัตรดิจิทัลพร้อม QR Code ตรวจสอบความถูกต้อง และระบบแจ้งเตือนผ่านจดหมายอิเล็กทรอนิกส์ (Email Notification) พร้อมระบบแจ้งเตือนผ่านเว็บแอปพลิเคชัน ซึ่งจะช่วยเพิ่มประสิทธิภาพในการบริหารงาน ลดภาระงานของผู้ดูแล และอำนวยความสะดวกแก่นักศึกษาอย่างมีประสิทธิผล

3. วัตถุประสงค์ของโครงงาน
  1. เพื่อออกแบบและพัฒนาระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรม คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร
  2. เพื่อประเมินประสิทธิภาพการทำงานของระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรม โดยผู้เชี่ยวชาญด้านเทคโนโลยีสารสนเทศ
  3. เพื่อศึกษาความพึงพอใจของนักศึกษาและบุคลากรผู้ใช้งานที่มีต่อระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรม
4. ขอบเขตของโครงงาน
4.1 ขอบเขตเนื้อหาและฟังก์ชันการทำงาน

ระบบถูกออกแบบตามสิทธิ์การใช้งาน (Role-based Access Control) โดยครอบคลุม 3 กลุ่มผู้ใช้หลัก ดังนี้:

1. สิทธิ์นักศึกษา (Student Role)

  • การลงทะเบียนเข้าสู่ระบบ ยืนยันตัวตน และจัดการข้อมูลโปรไฟล์ส่วนบุคคล
  • การค้นหาและเรียกดูรายละเอียดกิจกรรมบนปฏิทินกิจกรรมคณะแบบ Interactive
  • การจองสิทธิ์เข้าร่วมกิจกรรมล่วงหน้า พร้อมระบบจัดสรรคิวสำรองอัตโนมัติ (Waitlist)
  • การเช็คอินหน้างานด้วยสมาร์ตโฟนผ่านการสแกน QR Code ควบคู่กับการตรวจสอบพิกัด GPS Geolocation ในรัศมีสถานที่จริง
  • การส่งภาพถ่ายหลักฐานการเข้าร่วมกิจกรรม และการส่งซ้ำกรณีถูกปฏิเสธ
  • การตรวจสอบคะแนนกิจกรรมสะสมที่ได้รับการอนุมัติแล้ว และคะแนนที่อยู่ระหว่างรอตรวจสอบ
  • การเข้าถึงเกียรติบัตรดิจิทัล และการดาวน์โหลดเกียรติบัตรที่มีรหัสตรวจสอบ
  • การส่งออกกำหนดการกิจกรรมไปยังปฏิทินส่วนบุคคล (.ics Calendar Snapshot)
  • การรับการแจ้งเตือนผลการอนุมัติและเตือนกิจกรรมล่วงหน้า 1 วัน ผ่านระบบและจดหมายอิเล็กทรอนิกส์ (Email Notification)

2. สิทธิ์ผู้ดูแลระดับสาขาวิชา (Major Admin Role)

  • การจัดการกิจกรรมเฉพาะที่สังกัดสาขาวิชาของตน (เพิ่ม, แก้ไข, ปิดรับสมัคร)
  • การเรียกดูรายชื่อนักศึกษาที่ลงทะเบียนในกิจกรรมของสาขาวิชา
  • การตรวจสอบและอนุมัติหลักฐานภาพถ่ายกิจกรรมเป็นรายบุคคลหรือแบบกลุ่ม (Bulk Review) พร้อมระบุเหตุผลกรณีปฏิเสธ
  • การส่งออกรายงานสรุปการเข้าร่วมกิจกรรมของสาขาวิชาในรูปแบบไฟล์ CSV

3. สิทธิ์ผู้ดูแลระบบส่วนกลาง (Central Admin / สโมสรนักศึกษา)

  • การบริหารจัดการกิจกรรมทุกระดับทั้งคณะและมหาวิทยาลัย
  • การสร้าง QR Code เช็คอินหน้างานแบบ Real-time พร้อมกำหนดพิกัดละติจูด-ลองจิจูด และรัศมีระยะทาง
  • การบริหารจัดการบัญชีผู้ใช้งาน (เพิ่ม, แก้ไข, รีเซ็ตรหัสผ่าน, ลบบัญชี)
  • การจัดการภาพแบนเนอร์ประชาสัมพันธ์หน้าหลัก (Carousel Banner)
  • การเรียกดูสถิติภาพรวมบน Dashboard (จำนวนผู้ใช้งาน, จำนวนกิจกรรม, รายการรอตรวจ)
  • การตรวจสอบประวัติการทำรายการย้อนหลัง (Audit Logs Trail)
  • การกู้คืนข้อมูลที่ถูกลบชั่วคราว (Soft Delete & Trash Restoration)
  • การสำรองฐานข้อมูลออนไลน์และตรวจสอบความสมบูรณ์ของไฟล์สำรอง (Online Backup & Integrity Verification)
  • การตรวจสอบคิวงานส่งข้อความแจ้งเตือนภายนอก (Outbox Queue & Retry Delivery)
4.2 ขอบเขตการพัฒนา
  1. พัฒนาระบบในรูปแบบ Responsive Web Application รองรับการแสดงผลทั้งบนสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์ (ความกว้างหน้าจอตั้งแต่ 390px ขึ้นไป)
  2. สถาปัตยกรรมระบบฝั่งเซิร์ฟเวอร์พัฒนาด้วยภาษา Python ร่วมกับ Flask Framework และ Waitress WSGI Server
  3. ระบบฐานข้อมูลใช้ SQLite 3 ที่ทำงานในโหมด Write-Ahead Logging (WAL) พร้อมกำหนด Database Triggers เพื่อควบคุมสภาวะแย่งชิงทรัพยากร (ACID Concurrency Control)
  4. ระบบยืนยันตำแหน่งใช้ HTML5 Geolocation API ร่วมกับขั้นตอนวิธี Haversine Formula เพื่อคำนวณระยะทางจริงระหว่างผู้ใช้และสถานที่จัดงาน
  5. ระบบเช็คอินใช้ Dynamic Token เข้ารหัส HMAC-SHA256 ผูกกับ Nonce ในฐานข้อมูล มีอายุ 5 นาที ป้องกันการทำซ้ำ (Replay Attack)
  6. ระบบประมวลผลและลดขนาดภาพถ่ายหลักฐานด้วย Pillow Library เพื่อกำจัด Malicious Script และประหยัดพื้นที่จัดเก็บข้อมูล
  7. ระบบออกเกียรติบัตรดิจิทัลพร้อม Signed Serializer URL สำหรับสแกน QR Code ตรวจสอบความถูกต้องจากภายนอก
  8. ระบบส่งการแจ้งเตือนแบบอะซิงโครนัสผ่านสถาปัตยกรรม Outbox Pattern เชื่อมต่อบริการจดหมายอิเล็กทรอนิกส์ (SMTP Email) และการแจ้งเตือนบนเว็บแอปพลิเคชัน
4.3 ประชากรและกลุ่มตัวอย่าง

ประชากร: นักศึกษาคณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร ทุกชั้นปี และอาจารย์/บุคลากรที่รับผิดชอบงานกิจกรรมนักศึกษา
กลุ่มตัวอย่าง:

  1. นักศึกษาคณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร จำนวน 30 คน โดยใช้วิธีการเลือกแบบเจาะจง (Purposive Sampling) จากตัวแทนนักศึกษาทุกชั้นปีและหลากหลายสาขาวิชา
  2. กรรมการสโมสรนักศึกษาและตัวแทนผู้รับผิดชอบกิจกรรมประจำสาขาวิชา จำนวน 5 คน ทำหน้าที่ทดลองใช้งานระบบการจัดกิจกรรมและการอนุมัติ
  3. อาจารย์และผู้เชี่ยวชาญด้านเทคโนโลยีสารสนเทศและการพัฒนาเว็บแอปพลิเคชัน จำนวน 3 ท่าน เพื่อประเมินคุณภาพและประสิทธิภาพของระบบ
4.4 สถิติที่ใช้ในการวิเคราะห์ข้อมูล

1. ค่าเฉลี่ย (Mean) ใช้สูตร:

$$\bar{X} = \frac{\sum X_i}{n}$$

โดยที่ $\bar{X}$ = ค่าเฉลี่ย, $X_i$ = ค่าคะแนนของข้อมูลแต่ละตัว, $n$ = จำนวนผู้ตอบแบบประเมินทั้งหมด

2. ส่วนเบี่ยงเบนมาตรฐาน (Standard Deviation: S.D.) ใช้สูตร:

$$S.D. = \sqrt{\frac{\sum (X_i - \bar{X})^2}{n - 1}}$$

3. เกณฑ์การประเมิน (Likert Scale 5 ระดับ):

  • 4.51 – 5.00 หมายถึง มีประสิทธิภาพ / มีความพึงพอใจในระดับดีมาก
  • 3.51 – 4.50 หมายถึง มีประสิทธิภาพ / มีความพึงพอใจในระดับดี
  • 2.51 – 3.50 หมายถึง มีประสิทธิภาพ / มีความพึงพอใจในระดับปานกลาง
  • 1.51 – 2.50 หมายถึง มีประสิทธิภาพ / มีความพึงพอใจในระดับน้อย
  • 1.00 – 1.50 หมายถึง มีประสิทธิภาพ / มีความพึงพอใจในระดับน้อยที่สุด
5. เทคโนโลยีที่ใช้
5.1 เทคนิคหรือเทคโนโลยีที่ใช้
  1. GPS Geolocation & Haversine Formula: ตรวจสอบพิกัดละติจูด-ลองจิจูดของผู้ใช้งานเทียบกับสถานที่จัดงาน เพื่อให้มั่นใจว่านักศึกษาเข้าร่วมกิจกรรมในพื้นที่จริง
  2. HMAC-SHA256 Token with Nonce: สร้างโทเค็นเข้ารหัสลับสำหรับ QR Code เช็คอินที่มีการประทับเวลาและ Nonce ซึ่งหมดอายุภายใน 5 นาที เพื่อป้องกันการคัดลอกหรือถ่ายภาพส่งต่อ
  3. Cryptographic URL Serializer: ลงลายมือชื่อดิจิทัลบนรหัสเกียรติบัตรเพื่อป้องกันการแก้ไขปลอมแปลงข้อมูล (Tamper-proof Certificate Verification Link)
  4. Transactional Outbox Pattern & Background Worker: แยกการส่งข้อความแจ้งเตือนผ่านจดหมายอิเล็กทรอนิกส์ (SMTP Email Notification) ออกเป็นกระบวนการเบื้องหลัง (Background Process) เพื่อรับประกันความแน่นอนในการส่งข้อมูลและไม่หน่วงเวลาการตอบสนองของระบบ
  5. Database Concurrency & Triggers: การใช้ SQLite WAL Mode ร่วมกับ Trigger enforce_event_capacity_after_insert/update เพื่อควบคุมจำนวนที่นั่งระดับ ACID ป้องกันการจองเกินจำนวนพร้อมกัน
  6. Web Alert & Notification Modal: การออกแบบระบบหน้าต่างแจ้งเตือนและกล่องข้อความโต้ตอบบนหน้าต่างเว็บแอปพลิเคชันอย่างเป็นระเบียบและชัดเจน
  7. Responsive Web Design: ใช้เทคนิคโมเดิร์น CSS (Grid, Flexbox, Glassmorphism, Dark/Light Theme) เพื่อให้แสดงผลได้อย่างเหมาะสมบนทุกขนาดหน้าจอ

6. วิธีการดำเนินงาน

โครงงานนี้ดำเนินการตามวงจรการพัฒนาระบบเชิงระบบ โดยประยุกต์ใช้โมเดล ADDIE ดังนี้:

1. Analysis (การวิเคราะห์ความต้องการและปัญหา)

  • 1.1 ศึกษาประกาศ ระเบียบ และเกณฑ์การสะสมหน่วยชั่วโมง/คะแนนกิจกรรมของคณะวิทยาศาสตร์และเทคโนโลยี มรภ.สกลนคร
  • 1.2 เก็บข้อมูลและสำรวจปัญหาจากกลุ่มผู้ใช้งานเป้าหมาย ได้แก่ นักศึกษา สโมสรนักศึกษา และอาจารย์ผู้รับผิดชอบกิจกรรม
  • 1.3 วิเคราะห์ข้อกำหนดเชิงหน้าที่ (Functional Requirements) และข้อกำหนดที่ไม่ใช่เชิงหน้าที่ (Non-Functional Requirements)

2. Design (การออกแบบระบบและสถาปัตยกรรม)

  • 2.1 ออกแบบสถาปัตยกรรมระบบโดยรวม (System Architecture) และผังการไหลของข้อมูล (Data Flow Diagram: DFD)
  • 2.2 ออกแบบโครงสร้างฐานข้อมูล (Entity-Relationship Diagram: ERD) และพจนานุกรมข้อมูล (Data Dictionary)
  • 2.3 ออกแบบกลไกความมั่นคงปลอดภัย (Security Design) ได้แก่ การเข้ารหัสผ่าน, การยืนยันตำแหน่ง GPS, Dynamic HMAC Token และสิทธิ์การเข้าถึงข้อมูลตามบทบาท (RBAC)
  • 2.4 ออกแบบส่วนต่อประสานผู้ใช้ (UI/UX) ให้ใช้งานง่าย สวยงาม ทันสมัย และรองรับ Responsive Web บนทุกอุปกรณ์

3. Development (การพัฒนาระบบ)

  • 3.1 สร้างโครงสร้างฐานข้อมูล SQLite พร้อมจัดทำ Database Triggers และ Indexes สำหรับควบคุม ACID Concurrency
  • 3.2 พัฒนาระบบฝั่งเซิร์ฟเวอร์ (Backend) ด้วยภาษา Python และ Flask Framework เพื่อให้บริการ RESTful API
  • 3.3 พัฒนาระบบงานเบื้องหลัง (Outbox Worker) สำหรับจัดการคิวงานแจ้งเตือนทางจดหมายอิเล็กทรอนิกส์ (SMTP Email) และระบบแจ้งเตือนภายในเว็บ
  • 3.4 พัฒนาส่วนติดต่อผู้ใช้ฝั่งหน้าบ้าน (Frontend) ด้วย HTML5, CSS3 และ JavaScript เชื่อมต่อ API แบบ Asynchronous
  • 3.5 พัฒนาระบบออกเกียรติบัตรดิจิทัลพร้อมฟังก์ชันตรวจสอบความถูกต้องผ่าน QR Code

4. Implementation (การทดสอบและการทดลองใช้งาน)

  • 4.1 ทดสอบระบบอัตโนมัติด้วย Pytest ตรวจสอบความถูกต้องของ API, Business Logic และ Concurrency Controls
  • 4.2 ทดสอบ End-to-End Browser Testing ด้วย Playwright บนมุมมองจอมือถือ (390px) และจอคอมพิวเตอร์ (1366px)
  • 4.3 ติดตั้งระบบและนำไปทดลองใช้งานจริงกับกลุ่มตัวอย่างนักศึกษาและผู้ดูแลกิจกรรมจำนวน 35 คน
  • 4.4 สังเกตการณ์ บันทึกผลการใช้งาน และรับฟังข้อเสนอแนะในการปฏิบัติงานจริง

5. Evaluation (การประเมินผลและการสรุปผล)

  • 5.1 ประเมินประสิทธิภาพและคุณภาพของระบบโดยผู้เชี่ยวชาญด้านเทคโนโลยีสารสนเทศ จำนวน 3 ท่าน
  • 5.2 ประเมินความพึงพอใจของกลุ่มตัวอย่างนักศึกษาและผู้ดูแลระบบ โดยใช้แบบสอบถามมาตราส่วนประมาณค่า 5 ระดับ
  • 5.3 วิเคราะห์ผลข้อมูลทางสถิติ (ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน)
  • 5.4 สรุปผลการดำเนินโครงงาน จัดทำเอกสารคู่มือการใช้งาน และจัดทำรายงานฉบับสมบูรณ์

8. ประโยชน์ที่คาดว่าจะได้รับ
  1. ได้ระบบสารสนเทศบริหารจัดการกิจกรรมนักศึกษาและการตรวจสอบชั่วโมงกิจกรรมแบบบูรณาการที่ทำงานผ่านเว็บแอปพลิเคชันอย่างสมบูรณ์ และพร้อมนำไปใช้งานจริงในคณะวิทยาศาสตร์และเทคโนโลยี
  2. นักศึกษาได้รับความสะดวกรวดเร็วในการติดตามข่าวสาร จองกิจกรรม เช็คอินผ่านสมาร์ตโฟน และสามารถตรวจสอบคะแนนกิจกรรมสะสมและดาวน์โหลดเกียรติบัตรได้แบบเรียลไทม์
  3. สโมสรนักศึกษาและผู้ดูแลกิจกรรมประจำสาขาวิชา มีเครื่องมือดิจิทัลที่มีประสิทธิภาพในการจัดกิจกรรม ตรวจสอบรายชื่อ อนุมัติหลักฐาน และลดปัญหาการเช็คอินแทนกันได้อย่างมีประสิทธิผล
  4. คณะและมหาวิทยาลัย มีฐานข้อมูลกิจกรรมที่ถูกต้อง เชื่อถือได้ ปลอดภัย ลดปริมาณการใช้เอกสารกระดาษ (Paperless) และสามารถนำข้อมูลไปใช้ประกอบการประเมินคุณภาพการศึกษาและต่อยอดการพัฒนาในอนาคต
9. งานวิจัยที่เกี่ยวข้อง
ชื่องานวิจัย / ผู้วิจัย รายละเอียดพอสังเขป ความสอดคล้องกับโครงงาน
การออกแบบและพัฒนาระบบสารสนเทศกิจกรรมนักศึกษาผ่านเว็บแอปพลิเคชัน กรณีศึกษาสาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏพิบูลสงคราม
(ธนพล แย้มทุ่ง และ อรอุมา พร้าโมต, 2568) 		งานวิจัยนี้มุ่งเน้นการพัฒนาระบบสารสนเทศกิจกรรมนักศึกษาผ่านเว็บแอปพลิเคชันสำหรับสาขาวิชาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏพิบูลสงคราม เพื่อแก้ปัญหาการจัดการข้อมูลกิจกรรม การลงทะเบียน และการบันทึกประวัติการเข้าร่วมกิจกรรมที่กระจัดกระจายและไม่เป็นปัจจุบัน ผลการประเมินประสิทธิภาพโดยผู้เชี่ยวชาญมีความเหมาะสมในระดับมากที่สุด (x̄ = 4.62, S.D. = 0.49) และความพึงพอใจของผู้ใช้งานอยู่ในระดับมากที่สุด (x̄ = 4.58, S.D. = 0.52) สอดคล้องโดยตรงกับโครงงานในด้านการออกแบบสถาปัตยกรรมระบบสารสนเทศกิจกรรมนักศึกษาในบริบทของมหาวิทยาลัยราชภัฏ การจัดโครงสร้างฐานข้อมูลกิจกรรม และการออกแบบกระบวนการติดตามตรวจสอบชั่วโมงกิจกรรมของนักศึกษา
การพัฒนาระบบบริหารจัดการกิจกรรมนักศึกษา ด้วยกระบวนการแบบอไจล์
(ชรินทร์ญา หวังวัชรกุล และคณะ, 2568) 		งานวิจัยนี้นำกระบวนการพัฒนาซอฟต์แวร์แบบอไจล์ (Agile Methodology) มาประยุกต์ใช้ในการพัฒนาระบบบริหารจัดการกิจกรรมนักศึกษา โดยแบ่งบทบาทผู้ใช้งานเป็น 3 กลุ่ม ได้แก่ นักศึกษา เจ้าหน้าที่ และผู้บริหาร ระบบรองรับการเปิดรับสมัครกิจกรรม การเช็คชื่อผู้เข้าร่วม และการประมวลผลข้อมูลชั่วโมงกิจกรรมแบบอัตโนมัติ ช่วยลดข้อผิดพลาดและระยะเวลาการทำงานของเจ้าหน้าที่ได้อย่างมีนัยสำคัญ สอดคล้องในด้านการกำหนดบทบาทผู้ใช้งาน (Role-Based Access Control: RBAC) การจัดการสิทธิ์การเข้าถึงข้อมูลของนักศึกษาและผู้ดูแลกิจกรรม รวมถึงแนวทางการพัฒนาระบบที่ยืดหยุ่นและตอบสนองต่อการเปลี่ยนแปลงข้อกำหนดกิจกรรม
การพัฒนาเว็บแอปพลิเคชันเพื่อสนับสนุนการบริหารจัดการกิจกรรมนักศึกษาในมหาวิทยาลัยพิษณุโลก
(กิตติพงศ์ อุ่นแก้ว และคณะ, 2569) 		งานวิจัยนี้พัฒนาเว็บแอปพลิเคชันเพื่อสนับสนุนการบริหารจัดการกิจกรรมนักศึกษา โดยใช้ฐานข้อมูลเชิงสัมพันธ์และสถาปัตยกรรมเว็บสมัยใหม่ รองรับการลงทะเบียนออนไลน์ การสแกนคิวอาร์โค้ดเพื่อเช็คชื่อเข้ากิจกรรม และการสรุปรายงานสถิติการเข้าร่วมกิจกรรมเพื่อสนับสนุนการตัดสินใจของผู้บริหาร ผลการประเมินความพึงพอใจอยู่ในระดับมากที่สุด (x̄ = 4.65, S.D. = 0.48) สอดคล้องกับการนำเทคโนโลยี QR Code มาใช้ในการเช็คชื่อและยืนยันตัวตนผู้เข้าร่วมกิจกรรมหน้างานแบบเรียลไทม์ ตลอดจนการสรุปผลและส่งออกรายงานสถิติกิจกรรม
พฤติกรรมและแนวทางการพัฒนาประสิทธิภาพเว็บไซต์ด้านกิจการนักศึกษา: กรณีศึกษามหาวิทยาลัยมหิดล
(ธารีย์ณิชา ลีพีรวิทิต, และ ปเนต กุลฉันท์วิทย์, 2567) 		งานวิจัยนี้ศึกษาพฤติกรรมของผู้ใช้งานและแนวทางการพัฒนาประสิทธิภาพของเว็บไซต์ด้านกิจการและกิจกรรมนักศึกษา โดยประเมินการเข้าถึงข้อมูลข่าวสารกิจกรรม ความง่ายในการใช้งาน และประสิทธิภาพการตอบสนองของระบบ พบว่าการจัดหมวดหมู่ข้อมูลที่ชัดเจนและการแสดงผลที่รองรับอุปกรณ์พกพาส่งผลต่อการมีส่วนร่วมของนักศึกษาอย่างมีนัยสำคัญ ผลการประเมินความพึงพอใจโดยรวมอยู่ในระดับมาก (x̄ = 4.22, S.D. = 0.58) สอดคล้องในด้านการออกแบบสถาปัตยกรรมเว็บไซต์กิจกรรมนักศึกษา การจัดวางโครงสร้างสารสนเทศ (Information Architecture) และการพัฒนาส่วนติดต่อผู้ใช้ให้ตอบสนองต่อพฤติกรรมการใช้งานของนักศึกษาในระดับอุดมศึกษาอย่างมีประสิทธิภาพ
แอปพลิเคชันกิจกรรมนักศึกษา คณะวิทยาศาสตร์เทคโนโลยีและการเกษตร มหาวิทยาลัยราชภัฏยะลา
(อับดุลเลาะ ยาหะยอ, มูฮาหมัด กะลูแป, และ บุญธิดา จิรรัตนโสภา, 2564) 		การวิจัยนี้พัฒนาระบบเพื่อจัดการกิจกรรมนักศึกษาในระดับคณะวิทยาศาสตร์และเทคโนโลยีของมหาวิทยาลัยราชภัฏ เพื่ออำนวยความสะดวกในการจัดเก็บประวัติกิจกรรม การตรวจสอบสถานะการเข้าร่วมกิจกรรมของนักศึกษา และลดขั้นตอนการทำงานด้านเอกสารของฝ่ายพัฒนานักศึกษา ผลการประเมินความพึงพอใจอยู่ในระดับมาก (x̄ = 4.28, S.D. = 0.62) สอดคล้องในบริบทของการดำเนินงานในคณะวิทยาศาสตร์และเทคโนโลยีของมหาวิทยาลัยราชภัฏ ซึ่งมีโครงสร้างสาขาวิชาและเกณฑ์การเก็บชั่วโมงกิจกรรมที่สอดคล้องกัน โดยนำแนวทางมาประยุกต์ใช้ในการจัดหมวดหมู่กิจกรรมและการแสดงผลประวัติคะแนนของนักศึกษา
10. บรรณานุกรม (รูปแบบตาม APA7)

กิตติพงศ์ อุ่นแก้ว, มาริสา กัณฑาทรัพย์, ธมนวรรณ บุญไทย, ฤทธิรงค์ แสงสร้อย, และ ปรกฤษฎิ์ สายหัสดี. (2569). การพัฒนาเว็บแอปพลิเคชันเพื่อสนับสนุนการบริหารจัดการกิจกรรมนักศึกษาในมหาวิทยาลัยพิษณุโลก. วารสารวิชาการเทคโนโลยีอุตสาหกรรมและวิศวกรรม มหาวิทยาลัยราชภัฏพิบูลสงคราม, 8(2), 144–157.

คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏสกลนคร. (2566). คู่มือนักศึกษาและเกณฑ์การเข้าร่วมกิจกรรมเสริมหลักสูตร. มหาวิทยาลัยราชภัฏสกลนคร.

ชรินทร์ญา หวังวัชรกุล, ปฐมาวดี คำทอง, กัลย์สุดา อินทะวงค์, กัลยรัตน์ อาจปาสา, และ สิทธิชัย เสนานุช. (2568). การพัฒนาระบบบริหารจัดการกิจกรรมนักศึกษา ด้วยกระบวนการแบบอไจล์. วารสารวิทยาศาสตร์และเทคโนโลยี มทร.สุวรรณภูมิ, 9(3), 96–113.

ธนพล แย้มทุ่ง, และ อรอุมา พร้าโมต. (2568). การออกแบบและพัฒนาระบบสารสนเทศกิจกรรมนักศึกษาผ่านเว็บแอปพลิเคชัน กรณีศึกษาสาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏพิบูลสงคราม. วารสารก้าวทันโลกวิทยาศาสตร์, 25(1), 63–76.

ธารีย์ณิชา ลีพีรวิทิต, และ ปเนต กุลฉันท์วิทย์. (2567). พฤติกรรมและแนวทางการพัฒนาประสิทธิภาพเว็บไซต์ด้านกิจการนักศึกษา: กรณีศึกษามหาวิทยาลัยมหิดล. วารสารวิทยสารสนเทศและเทคโนโลยี, 5(2), 15–28.

อับดุลเลาะ ยาหะยอ, มูฮาหมัด กะลูแป, และ บุญธิดา จิรรัตนโสภา. (2564). แอปพลิเคชันกิจกรรมนักศึกษา คณะวิทยาศาสตร์เทคโนโลยีและการเกษตร มหาวิทยาลัยราชภัฏยะลา. ใน รายงานสืบเนื่องจากการประชุมวิชาการระดับชาติด้านวิทยาศาสตร์และเทคโนโลยีเครือข่ายภาคใต้ ครั้งที่ 6 (น. 455–462). มหาวิทยาลัยราชภัฏสงขลา.
